# 实验任务二：正则化和激活函数探索

## 1. 激活函数实验

### 1.1 激活函数的实现与可视化

> [!TIP]
>
> **为什么神经网络需要非线性激活函数？如果使用线性激活函数会发生什么？**

神经网络需要非线性激活函数，是因为只有非线性变换才能使网络具备逼近和表示复杂非线性关系的能力。如果仅使用线性激活函数，那么无论网络有多深，多层堆叠后仍然是一个线性函数，这样模型就无法捕捉复杂的数据模式，表现力和泛化能力都会受到严重限制。

### 1.2 梯度消失问题实验

> [!TIP]
>
> **观察实验结果，为什么训练准确率会和激活函数选择相关？这与梯度分布有什么关系？**
>
> **提示：**
>
> - **比较不同激活函数的梯度范围**
> - **分析梯度消失对模型训练的影响**
> - **思考为什么ReLU在深度学习中更受欢迎**

在该实验中，不同激活函数引出的梯度范围对模型训练有明显影响。Sigmoid 的输出范围在 (0,1) 内，当输入较大或较小时，其导数趋近于 0，容易出现梯度消失；而 Tanh 虽然输出在 (–1,1) 内，但梯度饱和问题依然存在，只是中心对称，有一定改善；ReLU 在正区间具有恒定梯度（即为 1），因此能保持较大的梯度信号，从而更有效地更新参数，提高了训练准确率。因此，实验结果中使用 sigmoid 的网络几乎没有提升，而 tanh 和 ReLU 的网络则有显著的准确率提升，这与各自梯度分布密切相关，也是为什么实际训练中 ReLU 更受欢迎的原因。

### 1.3 ReLU 死亡现象实验

> [!TIP]
>
> **ReLU 死亡现象的成因是什么？有哪些解决方案？**
>
> **提示：**
>
> - **分析什么情况下神经元会停止更新**
> - **思考学习率、初始化方式的影响**
> - **了解LeakyReLU等变体的优势**

- 成因：

  1. 神经元停止更新的情况：ReLU 在输入大于 0 时梯度为 1，小于等于 0 时梯度为 0。当神经元接收到负数输入时，激活值为 0，并且梯度也为 0，这就使得在反向传播时它们得不到有效的梯度更新。如果某个神经元的加权输入长期为负（例如由于参数更新过快、权重或偏置调整不恰当），那么这个神经元输出持续为 0，一旦进入这种状态，就很难再“复活”回来，因为梯度始终是 0。

  2. 学习率与初始化方式的影响
     - 较大的学习率可能使参数更新过于剧烈，导致网络权重和偏置的调整幅度过大，把神经元推到了负区，这样神经元很可能落入不能恢复的状态。
     - 不合适的初始权重（如初始化过小或过大）可能使得神经元初始输出偏负，从而更容易遭遇梯度为 0 的情况。

- 解决方案

   - 使用较小的学习率或者采用自适应学习率算法（如 Adam、RMSProp 等）可以减少参数更新时的剧烈波动，降低神经元突然“死亡”的风险。

   - 采用 He 初始化等专门为 ReLU 设计的权重初始化方法，可以使得初始激活值分布更为合适，从而降低进入零激活区的概率。

   - 使用 LeakyReLU、Parametric ReLU 或 ELU 等变体。

      - LeakyReLU 在输入小于 0 时不返回 0，而是返回一个较小的、线性变换的值（通常乘以一个很小的系数 α），这可以使得神经元即使在负区也具备一定的梯度，从而避免完全进入“死亡”状态。

      - PReLU 进一步将这个小系数作为可学习参数，使得模型可以根据数据自动调整负半部分的斜率。

      - ELU 则在负区域采用指数函数，可以在较大程度上保持梯度并让输出趋于一个平稳值。


## 2. 正则化方法实验

### 2.1 L2 正则化


> [!TIP]
>
> **使用 L2 正则化后，模型的参数会发生什么变化？为什么这种变化有助于防止过拟合？**
>
> **提示：**
>
> - **观察权重的数值分布变化**
> - **分析正则化系数λ的影响**
> - **思考为什么较小的权重有助于泛化**

使用 L2 正则化后，模型的参数会整体变小，即权重的绝对值会减小。

较小的权重能够使模型对训练数据中噪声的敏感度降低，增强模型的平滑性和泛化能力。较小的参数值意味着模型复杂度降低，因而能更好地提取数据中的主要信号而非噪声。同时，λ 控制了正则化项的权重，较大的 λ 会更强烈地约束参数，使得权重进一步缩小，但如果过大可能导致欠拟合；合适的 λ 能在防止过拟合与保持模型表达能力之间取得平衡。

### 2.2 Dropout

> [!TIP]
>
> **Dropout 为什么能够起到正则化的作用？训练时和测试时的差异处理有什么意义？**
>
> **提示：**
>
> - **分析 Dropout 的集成学习观点**
> - **思考为什么要进行比例缩放**
> - **考虑 Dropout 对特征依赖的影响**

Dropout 正则化作用的核心在于通过随机“丢弃”神经元来防止模型对某些节点或特征过于依赖，从而缓解过拟合问题。

在训练过程中，每一轮随机丢弃部分神经元，相当于从网络中采样出一个“子网络”进行训练。这意味着，事实上同时训练了大量共享参数、具有不同结构的子网络，从而使得模型预测时较难出现对特定节点或特征的依赖。测试时，我们不再随机丢弃，而是使用整个网络，并通过比例缩放使得每个神经元的输出相当于所有子网络平均的效果。这样，就相当于在测试时用一个“集成模型”来进行预测，通常会得到更好的泛化性能。

此外，每个神经元只有以一定概率被激活，因此其输出期望相较于未 dropout 时要减少。为了在测试时保证激活值的一致性，我们需要对全连接层或者卷积层的输出进行比例缩放，确保测试阶段的激活分布与训练时保持一致。若不进行这种缩放，模型在训练和测试阶段所看到的数据分布会不匹配，容易导致模型性能下降。

在没有dropout的网络里，神经元可能会“协作”产生过于紧密的特征依赖，这种共适应导致模型在面对新数据时表现得较为脆弱。通过 dropout，使得网络在每次迭代中只能依靠部分特征进行预测，从而迫使各个神经元学到更为独立、鲁棒的特征表示。这种特征的冗余和多样性在测试时能提高模型的稳健性和泛化能力。

训练与测试时差异处理的意义

- 训练时，通过随机丢弃部分神经元，模型学习到不依赖于特定神经元组合的鲁棒特征，从而降低过拟合风险。
- 测试时，使用全网络并进行比例缩放，则模拟了所有可能子网络的平均效果，相当于利用了集成的力量来提高预测准确率。这种方式不仅保留了在训练时获得的鲁棒特征，同时也能充分利用网络的全部参数，提高模型的整体表达能力。
